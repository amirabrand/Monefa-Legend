# Monefa Legend 🏰

> بازی استراتژیک آنلاین چندنفره (سبک Travian) — نسخه کامل با تمام فیکس‌های دیباگ‌شده

**Monefa Legend** یک بازی استراتژیک آنلاین در مرورگر است که در دنیایی با هزاران بازیکن روایت می‌شود. شما دهکده‌ای کوچک می‌سازید، منابع تولید می‌کنید، ارتش آموزش می‌دهید، با بازیکنان دیگر اتحاد تشکیل می‌دهید یا به آن‌ها حمله می‌کنید و در پایان برای فتح «عجایب جهان» (Wonder of the World) با اتحاد خود رقابت می‌کنید.

## 📋 پیش‌نیازها

- Ubuntu 20.04 / 22.04 / 24.04 (برای سرور اختصاصی یا VPS)
- PHP 8.1 تا 8.3 (برای cPanel هاست اشتراکی: PHP 8.1 یا 8.2)
- MySQL / MariaDB
- آپاچی با `mod_rewrite` (یا nginx — قوانین deny در README-INSTALL.md)

## 🚀 نصب روی سرور اوبونتو (یک فرمان)

```bash
# ۱) ریپو را کلون کنید
git clone https://github.com/amirabrand/Monefa-Legend.git
cd Monefa-Legend

# ۲) نصب کامل فقط با یک فرمان:
sudo bash install_ubuntu.sh \
     --domain=game.example.com \
     --admin-user=admin \
     --admin-pass='رمز-دلخواه-قوی' \
     --admin-email=you@example.com
```

اسکریپت خودش همه‌ی کارها را انجام می‌دهد:

1. نصب Apache + MariaDB + PHP و افزونه‌ها (mysql, mbstring, gd, curl, zip, xml, intl)
2. ساخت دیتابیس و کاربر با رمز تصادفی امن
3. کپی فایل‌های بازی به `/var/www/monefa-legend`
4. نوشتن کانفیگ در `/var/www/monefa-secure` (بیرون از web root)
5. ایمپورت دیتابیس از `_setup/travian.sql`
6. اجرای `install.php` (تعمیر فایل‌ها + ساخت اکانت ادمین + اتصال گرافیک)
7. ساخت vhost آپاچی + cron «ساعت بازی» (هر دقیقه)
8. در پایان: آدرس بازی، آدرس پنل ادمین، یوزر/رمز ادمین و رمز دیتابیس را چاپ می‌کند

> ⚠️ **cron حتماً باید فعال بماند** — بدون آن ساعت بازی (تولید منابع، حرکت نیروها، ساخت‌وساز) جلو نمی‌رود.

### نصب دستی (بدون اسکریپت)

```bash
sudo bash install.sh --db-user=USER --db-pass=PASS --db-name=DBNAME \
                     --host=game.example.com --admin-pass=SECRET
```

## 🖥️ نصب روی هاست cPanel

1. کل محتویات ریپو را zip کنید و در `public_html` آپلود و Extract کنید (فایل‌ها باید مستقیم داخل `public_html` باشند)
2. در cPanel → MySQL Databases یک دیتابیس + کاربر بسازید و با ALL PRIVILEGES وصل کنید
3. در مرورگر باز کنید: `https://دامنه-شما/install.php` و فرم را پر کنید
4. بعد از نصب: `install.php` و پوشه `_setup` را حذف کنید
5. Cron Jobs هر ۱ دقیقه: `/usr/local/bin/php /home/USER/public_html/dorf1.php >/dev/null 2>&1`

راهنمای کامل: [README-INSTALL.md](README-INSTALL.md) — شروع سریع: [README-FIRST.txt](README-FIRST.txt)
